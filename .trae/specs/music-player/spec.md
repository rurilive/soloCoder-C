# 音乐在线播放平台 - Product Requirement Document

## Overview
- **Summary**: 开发一个基于Python技术栈的音乐在线播放平台，集成免费音乐数据源，实现流媒体播放、音频可视化、个人歌单管理、歌曲图谱分析和智能推荐功能。
- **Purpose**: 提供一个功能完整的音乐播放体验，支持多源音乐元数据获取、在线播放、个性化歌单和智能推荐。
- **Target Users**: 音乐爱好者、开发者学习参考、个人音乐管理需求用户

## Goals
- **G1**: 集成多个免费开放的音乐数据源（Jamendo, MusicBrainz等），获取歌曲、专辑、艺术家等元数据
- **G2**: 实现后端流媒体转发服务，支持在线播放
- **G3**: 前端实现多种模式的音频可视化效果
- **G4**: 实现完整的个人歌单系统（创建、编辑、删除、添加/移除歌曲）
- **G5**: 构建歌曲知识图谱，分析歌曲、艺术家、专辑、风格之间的关系
- **G6**: 基于知识图谱实现歌曲推荐功能
- **G7**: 使用指定技术栈：Python + FastAPI + Jinja2 + SQLite + UV

## Non-Goals (Out of Scope)
- **NG1**: 不提供完整版权音乐的存储和分发服务（仅使用开放授权的音乐资源）
- **NG2**: 不实现用户注册登录系统（简化为单用户模式）
- **NG3**: 不实现社交功能（评论、分享、社区等）
- **NG4**: 不开发移动端APP（仅Web界面）
- **NG5**: 不实现实时音频处理或AI生成音乐功能

## Background & Context
- **技术栈选择**: Python生态系统成熟，FastAPI提供高性能异步支持，Jinja2用于服务端渲染，SQLite轻量级数据库适合个人项目，UV作为现代Python包管理器
- **数据源选择**: 
  - Jamendo: 提供Creative Commons授权的音乐，支持API搜索和流式播放
  - MusicBrainz: 开源音乐元数据数据库，提供丰富的歌曲、艺术家、专辑信息
  - TheAudioDB: 免费音乐数据库API
- **知识图谱**: 使用图数据库或邻接表存储歌曲关系，支持复杂的关联查询和推荐

## Functional Requirements

### 数据源集成
- **FR-1**: 支持Jamendo API集成，获取开放授权的音乐元数据和音频流
- **FR-2**: 支持MusicBrainz API集成，获取详细的音乐元数据
- **FR-3**: 支持搜索功能（按歌曲名、艺术家、专辑、风格搜索）
- **FR-4**: 本地缓存元数据，减少API调用次数

### 流媒体服务
- **FR-5**: 后端实现音频流代理/转发服务
- **FR-6**: 支持音频流的范围请求（Range Requests）实现进度控制
- **FR-7**: 支持播放、暂停、上一曲、下一曲、进度条控制
- **FR-8**: 支持音量控制和静音功能

### 音频可视化
- **FR-9**: 实现至少3种音频可视化模式
  - 模式1: 频谱柱状图
  - 模式2: 波形图
  - 模式3: 动态粒子效果
- **FR-10**: 支持可视化模式切换
- **FR-11**: 可视化效果与音频节奏同步

### 歌单系统
- **FR-12**: 支持创建、重命名、删除歌单
- **FR-13**: 支持向歌单添加/移除歌曲
- **FR-14**: 支持歌单列表展示和歌曲列表展示
- **FR-15**: 支持从歌单开始播放（顺序播放、随机播放、单曲循环）

### 歌曲图谱
- **FR-16**: 定义知识图谱实体类型：歌曲、艺术家、专辑、风格
- **FR-17**: 定义实体关系：演唱（艺术家-歌曲）、收录（专辑-歌曲）、属于风格（歌曲-风格）、合作（艺术家-艺术家）
- **FR-18**: 实现图谱的构建和持久化存储
- **FR-19**: 支持图谱查询（如：查询某艺术家的所有歌曲、查询某风格的热门歌曲）

### 推荐系统
- **FR-20**: 基于图谱的相似歌曲推荐（同风格、同艺术家）
- **FR-21**: 基于播放历史的推荐（用户偏好分析）
- **FR-22**: 基于"你可能喜欢"的推荐（图谱路径分析）
- **FR-23**: 推荐结果展示和一键添加到歌单

## Non-Functional Requirements

### 性能
- **NFR-1**: API响应时间 < 500ms（本地数据），< 3s（外部API）
- **NFR-2**: 音频流启动时间 < 2s
- **NFR-3**: 可视化渲染帧率 > 30 FPS

### 可靠性
- **NFR-4**: 外部API失败时有降级处理（使用本地缓存数据）
- **NFR-5**: 数据库操作有错误处理和日志记录
- **NFR-6**: 音频播放失败时有错误提示和自动跳过机制

### 可维护性
- **NFR-7**: 代码模块化，各功能模块解耦
- **NFR-8**: 合理的代码注释和类型注解
- **NFR-9**: 配置项集中管理（API密钥、数据源配置等）

### 安全性
- **NFR-10**: API密钥不硬编码在代码中（使用环境变量或配置文件）
- **NFR-11**: 不对外部暴露内部系统信息
- **NFR-12**: 数据库操作使用参数化查询防止SQL注入

## Constraints

### 技术
- **C-1**: 后端必须使用 Python + FastAPI
- **C-2**: 前端模板必须使用 Jinja2
- **C-3**: 数据库必须使用 SQLite
- **C-4**: 包管理必须使用 UV
- **C-5**: 前端可视化优先使用 Web Audio API 和 Canvas

### 业务
- **C-6**: 只能使用免费、开放授权的音乐数据源
- **C-7**: 遵守各数据源的API使用条款和速率限制
- **C-8**: 项目作为学习和个人使用，不用于商业目的

### 依赖
- **C-9**: Jamendo API 可用（需要申请免费API Key）
- **C-10**: MusicBrainz API 可用（无需API Key，但有速率限制）
- **C-11**: 网络连接可用（用于访问外部API和音频流）

## Assumptions

- **A-1**: 用户能够申请到Jamendo的免费API Key
- **A-2**: 外部API（Jamendo、MusicBrainz）在开发期间保持可用
- **A-3**: 用户浏览器支持Web Audio API（现代浏览器均支持）
- **A-4**: 运行环境有网络连接
- **A-5**: 单用户使用场景，无需多用户并发控制

## Acceptance Criteria

### AC-1: 数据源集成与搜索
- **Given**: 系统已配置好Jamendo和MusicBrainz API
- **When**: 用户输入搜索关键词（如"rock"或"贝多芬"）
- **Then**: 系统返回相关的歌曲、艺术家、专辑列表，包含标题、艺术家、封面图片等信息
- **Verification**: `programmatic`
- **Notes**: 验证搜索API返回正确格式的数据，包含必要字段

### AC-2: 流媒体播放功能
- **Given**: 用户选择了一首歌曲
- **When**: 用户点击播放按钮
- **Then**: 音频开始播放，进度条更新，支持暂停、拖动进度条
- **Verification**: `programmatic`
- **Notes**: 验证播放控制功能正常，音频流能够正常加载

### AC-3: 音频可视化
- **Given**: 歌曲正在播放
- **When**: 用户切换不同的可视化模式
- **Then**: 界面显示对应模式的动态效果，与音频节奏同步
- **Verification**: `human-judgment`
- **Notes**: 验证至少3种可视化模式，效果流畅且与音乐同步

### AC-4: 歌单CRUD操作
- **Given**: 用户在歌单管理界面
- **When**: 用户创建、重命名、删除歌单，添加/移除歌曲
- **Then**: 操作成功，数据持久化存储，界面正确更新
- **Verification**: `programmatic`
- **Notes**: 验证数据库正确更新，刷新页面后数据仍然存在

### AC-5: 歌单播放模式
- **Given**: 歌单中有多首歌曲
- **When**: 用户选择顺序播放、随机播放或单曲循环模式
- **Then**: 系统按照所选模式播放歌曲
- **Verification**: `programmatic`
- **Notes**: 验证每种播放模式的行为符合预期

### AC-6: 知识图谱构建
- **Given**: 系统已导入多首歌曲及其元数据
- **When**: 查询歌曲关系（如"查询该艺术家的其他歌曲"）
- **Then**: 系统能够正确返回关联的实体和关系
- **Verification**: `programmatic`
- **Notes**: 验证图谱关系正确存储和查询

### AC-7: 歌曲推荐功能
- **Given**: 用户正在播放某首歌曲或有播放历史
- **When**: 用户查看推荐列表
- **Then**: 系统返回相关的推荐歌曲，推荐理由可解释（如同风格、同艺术家）
- **Verification**: `programmatic`
- **Notes**: 验证推荐结果与当前播放歌曲或历史有明显相关性

### AC-8: 系统整体可用性
- **Given**: 系统启动完成
- **When**: 用户通过浏览器访问主页
- **Then**: 页面正常加载，所有功能模块可访问
- **Verification**: `human-judgment`
- **Notes**: 验证UI布局合理，功能入口清晰
